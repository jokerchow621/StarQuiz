`9x9-candidate.json` 於第一輪取代原 9×9 第一關；第二輪調整後位於正式題庫第 997 關。
它通過唯一解、色塊連通及行列／區域／相鄰限制驗證；一層假設固定點
仍無法解完，兩層可解完。檔案保留標準化棋盤、答案與完整驗證結果。

這輪目標是三層，針對既有兩層題聯動修改多處區域邊界，測試 3,354 個
通過結構驗證的候選，尚未找到完整驗證為三層的題目。
搜尋沒有找到三層題，不代表三層題不存在。驗證器節點數不能當成玩家
最短解法步數，也不能取代巢狀假設深度。
